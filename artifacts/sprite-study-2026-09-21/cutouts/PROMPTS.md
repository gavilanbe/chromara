# Recortes transparentes

Modo: imagegen integrado. Las salidas conservan el canal alfa generado.

## carmin — overworld

Use case: background-extraction. Input image is the edit target: the existing carmin overworld sprite sheet. Remove ONLY its light ivory background and make that background GENUINELY TRANSPARENT with an alpha channel. Output a PNG with actual transparent empty space, NOT an image of a checkerboard. Preserve exactly the same 1536 by 1024 canvas size, 4 columns and 4 rows, ALL SIXTEEN character sprites at the same locations, all pixels and colors inside the sprites, all faces, all silhouettes, beret or pencil apex or blue crest, and all small floating paint droplets. Keep eyes and highlights opaque. Do not redesign, repaint, smooth, rescale, move or crop any sprite. Do not add shadows, halos, glows or new objects. Empty space between and around the sprites must have alpha 0. Retain crisp pixel outlines without any white matte. This is solely exact background removal for a game atlas.
